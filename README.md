# OS Vision – Operating System Simulator

OS Vision is a Java Swing-based desktop application developed as a B.Tech Computer Science project. It demonstrates important Operating System concepts through interactive graphical interfaces.

## Features

- **CPU Scheduling:** FCFS, SJF and Round Robin.
- **Memory Management:** First Fit, Best Fit and Worst Fit.
- **Disk Scheduling:** FCFS, SSTF and SCAN.
- **Process Management:** Process states and state transitions.

## Technologies Used

- Java
- Java Swing
- Eclipse IDE

## How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project as an existing Java project.
4. Run `OSVisionApp.java`.
